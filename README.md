# 단원 정리본 만들기

중학교 영어 지필평가 대비 A4 정리본(단어·대화문·본문·문법 × 기본형/심화형 × 정리본/빈칸본)을 만드는 교사용 웹앱입니다.

- 주소: https://dnteacher.github.io/MiddleSchool-Unit-Sheets/
- 크롬·엣지에서 여세요. 인쇄 창에서 A4, 배율 기본(100%)으로 인쇄합니다.
- 단원 내용은 이 저장소에 올라가지 않고, 연 컴퓨터의 브라우저에만 저장됩니다. 다른 컴퓨터로 옮길 때는 앱의 ‘백업 파일 저장’ → ‘백업 불러오기’를 쓰세요.
- 앱에 들어 있는 예시 단원은 사용법을 보여 주려고 만든 글이며, 실제 교과서 내용이 아닙니다.
- 검색 엔진에 나오지 않도록 설정되어 있습니다 (noindex).
